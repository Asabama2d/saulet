# Атлас нормативов

`/norms` — отдельный защищённый раздел. Главный планировщик остаётся доступен без пароля.

В начальном графе представлены все документы и все извлечённые пункты/фрагменты. Точки группируются вокруг документа. На общем масштабе карта рисуется в буфер Canvas, вблизи доступны отдельные точки и связи с документом. Линии между документами означают найденные в выдержках упоминания шифров. Это автоматически найденные связи, не полный реестр нормативных ссылок.

Темы сопоставляются по корням слов; темы типов зданий также наследуются из названия документа. Можно выбрать пересечение или объединение нескольких тем. Полнотекстовый поиск использует отдельный словарь и выполняется в Web Worker; слова запроса соединяются условием И, поиск идёт по началу слова. Доступны фильтры языка и раздела, список результатов, страницы оригинала, таблицы, копирование цитаты и полный Markdown документа.

## Данные и ограничения

- Импорт сверяет число Markdown-файлов с `INDEX.md`, обходит только 11 нормативных разделов. Папки с результатами работы, скрипты и личные проекты не импортируются.
- Полный текст каждого документа сохраняется после нормализации переводов строк. Индекс содержит границы фрагментов, исходный путь, номер страницы, SHA-256 и метаданные из шапки.
- Это 695 Markdown-документов, а не все исходные PDF: список нераспознанных файлов доступен в «Составе базы».
- Нумерация, язык, тематические связи и границы распознаны автоматически. Возможны OCR-ошибки и смешанные языки. Год из шифра не является датой последнего изменения. Актуальность и применимость не подтверждены автоматически.
- Атлас служит источником для проверки. Импорт не превращает текст в расчётные правила и не изменяет существующие нормативные вычисления планировщика.

## Защита

В публичном репозитории и на статическом хостинге хранятся только зашифрованные тексты, индекс и словарь. Открытый manifest раскрывает только технические параметры и количества. Импорт создаёт случайный 192-битный пароль в `.saulet-key` **вне репозитория**. Ключ AES-256-GCM выводится с PBKDF2-SHA-256, 600 000 итераций, случайной солью 128 бит. Для каждого файла генерируется независимый IV 96 бит; идентификатор выпуска и имя файла аутентифицируются как AAD, tag — 128 бит. Gzip выполняется до шифрования.

Браузер использует [Web Crypto](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveKey) и [AES-GCM](https://developer.mozilla.org/en-US/docs/Web/API/AesGcmParams). Пароль не отправляется на сервер и не сохраняется приложением. Невыгружаемый CryptoKey и расшифрованные данные существуют в памяти вкладки. Закрытие доступа уничтожает Worker и состояние интерфейса; через 30 минут бездействия раздел блокируется.

Это общий ключ к зашифрованному архиву, а не персональные учётные записи. Получатель ключа может сохранить документы. Смена ключа не отзывает ранее скачанные тексты или старые зашифрованные версии с известным старым ключом. Не используйте короткий придуманный пароль: публичные шифротексты допускают офлайн-перебор. Для персонального отзыва доступа, журналирования и индивидуальных аккаунтов нужен серверный вариант.

## Обновление базы

```powershell
npm run corpus:import -- --source 'D:\path\_MD' --key-file 'C:\private\Saulet-access.saulet-key'
npx tsx scripts/verify-corpus.ts --source 'D:\path\_MD' --key-file 'C:\private\Saulet-access.saulet-key'
npm test
npm run lint
npm run typecheck
npm run build
```

Если файла ключа ещё нет, импорт создаёт его. Существующий ключ используется повторно, но соль, IV и идентификатор выпуска обновляются. Никогда не добавляйте ключ, расшифрованный корпус или локальный каталог источников в Git. Каждый выпуск самодостаточен, старые выпуски можно удалять отдельно после проверки; это не удаляет их из истории Git.

Тесты проверяют отказ при неверном пароле, изменённом шифротексте и подмене имени файла, расшифровку через браузерный Web Crypto, страницы/границы, исключение оглавления из нумерованных пунктов и пересечения тем. Отдельная проверка сравнивает все расшифрованные документы с локальными исходниками и проверяет все диапазоны и поисковые ссылки.
